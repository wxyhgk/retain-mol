## 结束检查

```text
□ 页面仍可响应点击和旋转
□ 没有持续“处理中”状态
□ 没有明显重复原子、重复键或断裂键
□ 浏览器 console 没有新增 error
□ 所有“阻塞/体验问题”均已登记问题编号
```

## 记录原则

- 不在一次检查里构造复杂目标分子；每个动作只验证一种能力。
- 不用“偶尔”“感觉不对”作为复现步骤，记录点击对象、当前工具和预期结果。
- 视觉问题必须附截图；导入问题必须附原始 SDF/XYZ 文件。
- 卡死问题记录最后一个成功动作，以及卡死前的分子文件。
