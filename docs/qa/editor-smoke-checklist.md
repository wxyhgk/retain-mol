## 结束检查

```text
□ 页面仍可响应点击和旋转
□ 没有持续“处理中”状态
□ 没有明显重复原子、重复键或断裂键
□ 浏览器 console 没有新增 error
□ 所有“阻塞/体验问题”均已登记问题编号
```

## 记录原则

- 不在一次检查里构造复杂目标分子；每个动作只验证一种能力。
- 不用“偶尔”“感觉不对”作为复现步骤，记录点击对象、当前工具和预期结果。
- 视觉问题必须附截图；导入问题必须附原始 SDF/XYZ 文件。
- 卡死问题记录最后一个成功动作，以及卡死前的分子文件。


## 检查器与键盘专项

实现和验证状态见 [检查器与快捷键](../UI/inspector-and-shortcuts.md)。

| 动作 | 最小预期 |
| --- | --- |
| 桌面宽度下打开、拖动分隔条、收起检查器 | 检查器不覆盖画布；两个编辑器保留内容；3D 可以继续旋转、适配 |
| 激活 Draw，选 O，再收起并重新打开检查器 | Draw 与 O 画笔保留，展开状态读数正确 |
| 在原子坐标字段输入草稿，按 Escape | 只取消该字段草稿；检查器和工具保持 |
| 在检查器按钮上按 Escape | 收起后焦点回到顶部检查器开关 |
| 在 3D 画布按 Cmd/Ctrl+K | 只出现命令面板；上下键跳过禁用项，Enter 执行；Escape 关闭 |
| 打开命令面板并将焦点移到命令按钮，再按 Delete、Cmd/Ctrl+Z、粘贴 | 背景分子的结构、选择和历史不变 |
| 从命令面板打开 PubChem，再按 Escape | 焦点进入 PubChem；关闭后回到命令入口；不会改变绘制模式 |
| 将宽度缩至 1000 px，主动打开检查器，再关闭 | 默认收起，主动打开才出现模态；关闭保留画笔，焦点回开关 |
| 在窄屏模态的数字字段按 Escape 两次 | 第一次取消字段，第二次关闭模态；背景分子不变 |
| 2D 画布有焦点时使用 Delete、撤销、复制／粘贴 | 只影响 2D 编辑器的本地操作，不额外触发背景 3D 命令 |
