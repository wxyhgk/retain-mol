# 螺芴空间避让 Demo

主应用入口 `/?demo=steric`，或通过主编辑器命令面板的「螺芴碰撞避让 Demo」打开新标签页。两个独立 ViewerRuntime 展示当前结构与候选，不读写主编辑器的草稿、历史或保存记录。

## 启动

```sh
npm run dev --workspace retainmol
# http://localhost:5300/?demo=steric
```

Vite 默认监听局域网。端口占用时显式指定空闲端口，例如 `-- --port 5301`，不停止现有编辑器。

真实 Jev 请求需要由启动进程继承 `TYPESAFE_API_KEY`，可选 `TYPESAFE_MODEL`（默认 `jev-latest`）。密钥通过本机安全通道提供，不写入仓库、浏览器、URL 或日志，不使用 `VITE_` 前缀。未配置密钥时仍可完成本地分析、预览、应用与撤销。

同源 `/api/demo/steric/choose` 由 Vite 插件提供，开发和 `vite preview` 都可使用；静态托管不包含此服务，需要另行部署宿主服务端。GET 只返回是否配置及模型别名；POST 验证不超过六个候选，向 TypeSafe 发送一次 choice 请求，15 秒超时，不自动重试。跨域请求被拒绝，错误不返回上游原始响应体。

## 操作链路

1. 载入「拥挤初态」：C32H22，54 个原子（显式氢），3 对严重重叠。
2. 分析 24 个侧链姿态，18 个通过当前策略；保留六个有代表性的候选。初始预览按本地拥挤评分选择，不冒充 Jev 推荐。
3. 点击候选比较指标。左侧当前结构和历史不变；接触报告条目可选中原子并聚焦。
4. 选择「尽量展开」或「尽量少动」，可补充一句话；有密钥时点击 Jev 推荐，显示实际模型版本、耗时与概率。模型也可选择 none。
5. 点击应用才提交，产生一次撤销记录。再次应用已过期候选会失败。修改样例、偏好或历史会取消旧推荐。
6. 「正常姿态」检查无严重重叠；「锁定后无法避让」检查没有可用自由度时的明确反馈。

## 公开 API

通过 `@retainmol/mol-viewer/headless` 使用：

- `analyzeStericContacts(molecule)`：只读，返回原子对、实际距离、严重/接触阈值、分离键数分类、单位、策略版本、显式氢覆盖和汇总。
- `generateTorsionCandidates(context, {targetObjectId, bondId, movingAtomId, fixedAtomIds})`：只读，返回采样/通过数量、诊断和最多六个候选。每个候选带 molecule、revision、metrics、EditPlan。

核心功能不依赖 Jev、网络、React 或渲染器。候选用现有 geometry.rotateGroup + dryRunEditPlan 生成；宿主在应用时重新执行 dry-run，核对预览 revision 和碰撞结果后，通过 commitEditPlan 原子提交。

## 几何策略和边界

`ch-contact-v1` 是演示用几何启发式，不是能量、力场或化学有效性判据：

- 仅支持中性、无自由基 C/H；候选搜索要求完整显式氢和有效输入拓扑。未支持元素和非有限坐标明确报错。
- 直接成键以及相隔两键的原子不计非键接触。相隔三键的短接触只警告。
- 更远原子对的严重阈值沿用 `(共价半径 A + 共价半径 B) × 0.72`。
- 拥挤接触参考半径独立于渲染球大小：C 1.70 Å、H 1.20 Å。数据沿用项目既有 C/H 参考数值，单独声明为演示策略，不宣称完整科学参数化。小于半径和的接触计入 `Σ overlap²`，包括三键相邻警告。
- 移动 RMS 是所有原子的均方根位移；展开半径是所有原子无质量加权的回转半径，单位均为 Å。
- 单键 0°–345°、步长 15°；不旋转芳香键、环内键、双键或锁定移动组。固定核心不动，候选保持拓扑、键长及指定立体信息。
- 搜索失败只表示这些采样未找到结果。没有严重重叠不证明低能或稳定；不保证旋转动画的整条路径不会穿环。

固定 fixture 由项目已有 OpenChemLib 距离几何一次生成，记录结构来源，随后仅改变侧链扭转以构造拥挤态；不做力场优化。运行 demo 不重新生成坐标、不联网检索分子。

- 定向测试：碰撞策略与空间索引对照、样例结构、可重复候选、输入顺序独立的指标、约束拒绝、预览无副作用、提交/撤销/重做/过期拒绝。

- `npm run verify` 全部通过：凭据扫描、形式化几何检查、包边界、lint（14 项既有警告、无错误）、类型检查、各包测试、生产构建、20 个公共入口 API 报告、打包自测及独立消费者验证。
- 新增 16 项定向测试；全仓 Vitest 共 1,262 项通过，另含既有 Node/形式化检查。
- Edge 生产预览实操通过：双视口、24 个采样/18 个通过/6 个候选、预览不改变当前重叠数、应用 3→0、撤销 0→3、重做 3→0、正常姿态、锁定失败及偏好切换。
- 真实 Jev 调用未验证：当前进程没有 `TYPESAFE_API_KEY`。缺密钥状态已在真实浏览器确认；模拟上游测试不代表模型分子决策准确率。
- 窄屏、任意分子、真实 Jev 推荐和连续旋转防穿透未完成浏览器验收；本版不作这些能力的完成声明。
