# mol-viewer 手性正确性

2026-09-20 修复范围：绝对 R/S 设置、编辑后的原子手性一致性、AI 效果快照，以及几何构型与指定状态的独立显示。

## 行为

- 3D 徽标与检查器区分当前几何的 CIP 读数和 `Atom.chirality` 指定状态：
  未指定但可感知的中心显示灰色 `R·未指定` / `S·未指定`；指定且与几何一致时显示紫色 R/S。
  不再用 `?` 表示未指定。无法感知且没有指定的原子不显示手性徽标。
- 2D 无楔形的 `CC(F)(Br)I` 可以生成一个带 R/S 的 3D 构象，但输入仍未指定立体化学。
  检查器分别显示「当前构型」「指定状态」；选择 R/S 才写入指定状态。
  清除指定保留 3D 坐标与可感知读数；翻转未指定中心也不会自动指定。
  未记录坐标来源，因此 UI 不把所有未指定的 3D 构型都声称为「自动生成」。
- 外部传入的指定状态若与感知结果冲突，检查器保留两者，徽标显示实际读数加「不一致」；
  有指定但无法感知时显示「待核验」，不伪装成已确认的 R/S。
- 宿主的 2D→3D 自动同步忽略 MOL 文件头的导出时间戳。Indigo 每分钟改变该字段，
  不能据此重新导入未变化的 2D 结构，否则会清掉用户在 3D 中指定的手性与选择。
  坐标、元素、楔形、维度标志等实际变化仍触发同步；手动「同步到 3D」仍强制导入。
- `setChirality` 用 OpenChemLib 的 CIP 结果选择是否交换分支，并复核结果；不再把
  `bonds` 数组顺序的体积正负或 OCL 相对 atom parity 当作 R/S。
- R/S 翻转用绕中心的互逆刚性旋转交换两根键的方向，各自键长不变；分支内部距离、
  连接角及分支中其他手性中心保持。原先整体平移互换位置会把 C—F / C—Br 键长交换，
  现已移除该行为。共享分支或一条分支通过环回连中心其他配体时，不允许搬动该分支。
  翻转前后均复核实际 CIP，无法安全翻转时不写入几何。
- E/Z 的分支交换复用相同的保长旋转底座，并复核现有 E/Z 几何判定结果。
  此处仅修复键长保持，不扩展现有 E/Z 优先级判定范围。
- 设置仍限 C/Si、四个显式且化学不同的单键配体、非退化几何。隐式 H 需先显式化。
  无法确定 CIP 或无法独立交换分支时，命令返回失败，不能只贴目标字母。
- 修改元素、删除、移动及 store/headless 落盘时重新感知已有标记。优先级改变则更新 R/S，
  中心失效则去掉标记和该中心拥有的楔形；未指定中心仍未指定。撤销/重做与结构编辑在同一事务。
- 楔形归属窄端 `atomId1`。清除一个中心时保留邻居拥有的入向楔形。
- MOL 导出从实际坐标/2D 楔形计算立体构型。用临时原子映射处理 OCL 显式氢重排，
  避免把原始坐标写给另一原子；临时映射不写入产物。单独改 `chirality` 字段不能替代几何编辑。
- ExpectedEffect V2 / `canonical-v4-sha256-` 包含 R/S、楔形方向及窄端、E/Z 和同位素质量数。
  历史 V1 回执与 V2 不可混用。此变更不宣称新的 E/Z 设置算法或完整 CIP/形式化证明覆盖。

## 只读 API

```ts
import { getAtomChiralityState } from '@retainmol/mol-viewer/core'

const { specified, computed } = getAtomChiralityState(molecule, atomId)
// specified: 模型中已指定的 R/S，未指定为 null
// computed: 从当前坐标 / 2D 楔形感知的 R/S，非手性或无法判定为 null
```

浏览器与 Node 共用；不会修改分子或增加历史记录。按不可变分子快照缓存整分子的感知结果，
逐帧读取不重复运行 CIP；坐标或拓扑编辑必须产生新的 `Molecule` 对象。
缺失的 atomId 返回两个 null。此读数不代表对全部 CIP 情形或构象生成可靠性的额外保证。

CIP 使用现有 OpenChemLib 依赖。无法感知时清除现有标记；没有增加同位素、轴手性、
伪不对称中心或复杂环系的编辑支持。独立 ExpectedEffect 与生产编辑共享 CIP 感知器，
MOL 往返及两种 RDKit 锚点不代表全部立体化学情形已被证明。
分支旋转保持既有局部几何，不保证新分支之间无碰撞或达到能量极小；能量优化仍是显式操作。
