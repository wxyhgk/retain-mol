# mol-viewer 手性正确性

2026-09-20 修复范围：绝对 R/S 设置、编辑后的原子手性一致性、AI 效果快照。

## 行为

- `setChirality` 用 OpenChemLib 的 CIP 结果选择是否交换分支，并复核结果；不再把
  `bonds` 数组顺序的体积正负或 OCL 相对 atom parity 当作 R/S。
- 设置仍限 C/Si、四个显式且化学不同的单键配体、非退化几何。隐式 H 需先显式化。
  无法确定 CIP 或无法独立交换分支时，命令返回失败，不能只贴目标字母。
- 修改元素、删除、移动及 store/headless 落盘时重新感知已有标记。优先级改变则更新 R/S，
  中心失效则去掉标记和该中心拥有的楔形；未指定中心仍未指定。撤销/重做与结构编辑在同一事务。
- 楔形归属窄端 `atomId1`。清除一个中心时保留邻居拥有的入向楔形。
- MOL 导出从实际坐标/2D 楔形计算立体构型。用临时原子映射处理 OCL 显式氢重排，
  避免把原始坐标写给另一原子；临时映射不写入产物。单独改 `chirality` 字段不能替代几何编辑。
- ExpectedEffect V2 / `canonical-v3-sha256-` 包含 R/S、楔形方向及窄端、E/Z。
  历史 V1 回执与 V2 不可混用。此变更不宣称新的 E/Z 设置算法或完整 CIP/形式化证明覆盖。

## 验证

- 回归覆盖原子/键顺序变化、R/S 文件往返及坐标身份、对称配体、优先级变化、平面化、
  未指定中心、楔形归属、独立 ExpectedEffect 与 headless 执行一致、单步 undo/redo。
- `mol-viewer` 148 个测试文件、867 项测试通过；严格类型检查、API 报告及打包消费检查通过。
- 根 `npm run verify` 已通过；原有 lint 仍有 15 条 warning，无 error。
- Python Node 执行器集成及最终产物 gate 26 项通过，包括手性回执篡改和版本混用拒绝。
- RDKit 独立读取公开 store 设置 R/S 后的 MOL 产物，两种构型均与目标相符；用例含氢原子前置及键重排。
- 真实浏览器能打开生产构建的命令面板。文件导入被浏览器扩展文件权限阻止，
  因此未完成导入→点击设置手性→编辑→撤销的 UI 验收；store 事务和文件行为已由上述测试覆盖。
  开发宿主另遇到 vendored 2D 编辑器的 `emitter.off` 错误，不属于本次修复。

CIP 使用现有 OpenChemLib 依赖。无法感知时清除现有标记；没有增加同位素、轴手性、
伪不对称中心或复杂环系的编辑支持。独立 ExpectedEffect 与生产编辑共享 CIP 感知器，
MOL 往返及两种 RDKit 锚点不代表全部立体化学情形已被证明。
