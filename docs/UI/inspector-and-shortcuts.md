# 检查器停靠与快捷键作用域

2026-09-21，第一批基础交互改造。应用职责留在 `apps/retainmol`，不新增包或命令引擎。

## 当前行为

- 视口宽度至少 1200 CSS px 时，检查器参与横向布局，可以通过分隔条调整宽度，也可以通过顶部按钮或面板内按钮收起。宽度约束为 320–480 px，且不超过工作区的 40%。2D/3D 编辑器的组件身份保持稳定，收起检查器不会重建编辑器。
- 小于 1200 px 时默认收起；主动打开才使用临时模态检查器。跨越断点会关闭临时弹窗。桌面开关、窄屏开关和当前标签保存在独立的 `inspectorStore` 中，工具和画笔仍由原控制器管理。
- 激活绘制工具会在桌面打开 Draw 标签；在窄屏不会自动弹窗。之后收起检查器保留当前工具、画笔和上次绘制操作。再次打开保留标签。
- 桌面检查器为命名的 `aside`；按钮的 `aria-expanded` 与实际显示一致，`aria-controls` 指向检查器。仅在关闭时焦点位于面板内，才将焦点交还开关。窄屏弹窗关闭后交还开关。
- `Cmd/Ctrl+K` 由工具栏独占，打开命令面板。PubChem 是面板中的命令，无同名快捷键。命令搜索支持 Enter 执行第一个可用结果、上下方向键移动到命令按钮、Tab 切换；禁用命令不会被执行。PubChem 也使用现有 Dialog 管理焦点。
- 3D 画布具有可读名称，可获得键盘焦点。平面模式的 `pp` 快捷键只由获得焦点的查看器处理。

## 按键和剪贴板边界

已处理的事件、输入法组合输入、文本输入、原生 select、自定义 combobox 等不触发背景工作区快捷键。`data-shortcuts="local"` 标记的检查器与 2D 编辑器拥有自己的事件；打开的原生 dialog（包括 Ketcher 弹窗）、活动模态弹窗、菜单和应用覆盖层阻止背景快捷键及分子粘贴。

Escape 的顺序为：当前字段取消编辑；当前菜单／弹窗关闭；活动 gizmo 拖拽取消；画布平面模式退出；待确认测量取消；宿主工具退出。数字字段第一次 Escape 取消草稿并失焦，不连带关闭检查器。模态库在 document capture 处理 Escape，窄屏检查器对此字段做了显式让步。普通拖拽期间不打开命令面板／临时检查器，也不执行工作区快捷编辑和历史操作。

查看器保留自己的 DOM 事件适配，应用保留工作区规则；没有给基础模型、headless 或公共 JSON 引入浏览器依赖。嵌入宿主可用 `data-shortcuts="local"`、标准模态角色或 `data-shortcut-overlay="true"` 声明前景操作区域。

## 目标保护的行为调整

`edit.removeHydrogens({ onlySelected: true })` / 对应 store 方法在空选择或选择包含活动分子之外的 ID 时不修改分子、不新增历史。未知 ID 先被选择接口过滤成空集，也不会退回全分子删除。

**兼容性说明：** 以前 `onlySelected: true` 且空选择会去除整个分子的显式氢。需要整分子操作的调用方应明确调用 `removeHydrogens()` 或传 `onlySelected: false`。有效选择保留局部移除与一步撤销语义。

## 第二批：可定位的对象与操作结果

2026-09-21。通过 Inspector 标签可以完成：搜索原子 → 选择 → 显式聚焦 → 替换元素 → 阅读结果 → 撤销。原子与键共用浏览器，所有数据来自当前活动分子。

- 顶部摘要提供活动分子名称、原子／键总数、工具、有效选择数，以及忙碌／锁定／隐藏状态。
- 搜索支持精确元素（`O` 不会匹配随机 ID 中的字母）、当前编号（`12` 或 `#12`）、标签子串、`id:完整 ID`（区分大小写）。键的元素搜索匹配任一端点。分页每页 20 项，支持仅显示已选项；过滤后页码会限制在有效范围，切换分子会重置列表条件。
- 列表使用原生按钮、搜索输入框、下拉框和复选框，具有可读名称。`aria-pressed` 反映当前选择；结果数和最近操作使用 `role=status`。列表不会一次输出整张分子图或全部邻接信息。
- 选择按钮切换到选择工具并解除画笔；保留相机位置。聚焦按钮明确先选择、再调用既有视口聚焦 API。视口未挂载时显示“已选择但未聚焦”，不声称相机已移动。
- 属性区显示稳定 ID，选中一个原子时才显示其邻接键。邻接原子可以继续选择；键详情可修改键级。
- 最近结果保留至下一次受支持的操作或页面重载，收起检查器／切换标签不会清除。当前记录范围是列表／邻接定位、元素替换、单键对象的键级编辑，以及其撤销；其他既有编辑仍保留原交互，尚未统一接入结果展示。
- 元素和键级编辑通过 `commitEditPlan` 返回实际成功、无变化或拒绝原因。每次成功编辑只占一步撤销；无变化、无效输入和过期目标不新增历史，也不清空 redo。
- 每个目标携带 `objectId + entityId + expectedRevision`。显示编号不是编辑地址；调用时重新检查活动对象、实体存在、版本、可见性、锁定与忙碌状态。控件禁用是 UI 提示，执行前的守卫仍独立生效。
- “撤销本次编辑”还核对整场景引用及历史栈顶；其他编辑、场景变化、历史清空、切换／隐藏／锁定目标会使按钮不可用，点击时再次检查。不会把后续无关编辑作为本次编辑撤销。

实现边界：列表投影、React 状态和结果展示在 `features/inspector`；运行时读写集中在 `domain/viewer/inspectorActions.ts`。复用现有 modeling、runtime 和状态入口，没有新增包、JSON 契约或公开命令引擎。当前适配应用的默认 viewer runtime，未宣称是任意嵌入宿主的通用控制器。
